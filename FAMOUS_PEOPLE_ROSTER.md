Source input for Tier 0.2 (`src/lib/seo/famousPeopleContent.ts`) and Tier 0.3
(`famousExamples` wiring + "Famous [Type]" pages).

Every entry here is Colevitate's **editorial, speculative typing** grounded in
well-documented public behavior, interviews, or biography — never presented
as the person's own quiz result or as settled fact. That framing must carry
through into the actual page copy in 0.2, not just live here.

**Human Design is intentionally blank for the entire roster.** The rule (see
IMPROVEMENT_PROMPTS.md 0.1) is: only assign where exact birth date, time,
*and* location are reliably publicly documented. That bar is met for almost
no one across these four categories without pulling from unevenly-reliable
astrology-community sources. If a Human Design pass is wanted later, treat it
as a separate, narrower research task using data-quality-rated sources (e.g.
Astro-Databank's AA/A-rated entries), not folded into this roster.

Photo-availability notes below are directional, not a license clearance —
0.2 still needs to confirm and record the actual license + attribution text
per photo before shipping it.
